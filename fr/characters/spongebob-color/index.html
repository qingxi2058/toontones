Code hex du jaune de Bob l'éponge

La couleur classique du corps de Bob l'éponge est un jaune chaud, légèrement verdâtre. La valeur retenue par la plupart des sources est #F9E03B (RGB 249, 224, 59). Comme le personnage apparaît dans la série, les logos et les produits dérivés, on rencontre quelques variantes proches :

FAQ sur la couleur de Bob l'éponge

De quelle couleur est Bob l'éponge ?

Bob l'éponge est jaune vif. Le code hex le plus utilisé est #F9E03B, et #FFF359 est aussi cité selon la source et l'écran.

Quel est le code hex du jaune de Bob l'éponge ?

Le code hex est #F9E03B (RGB 249, 224, 59). D'autres valeurs vues sur les logos et produits incluent #FFF359 et #F9E24D.

Quelles sont les autres couleurs de Bob l'éponge ?

Outre son corps jaune, il porte une chemise blanche, une cravate rouge (env. #D62828), un pantalon marron (env. #A56E3A) et a des yeux bleus (env. #4FB0E5).
